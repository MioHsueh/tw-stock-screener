# 台股量縮均線糾結選股網站

## 篩選條件
- 台股上市＋上櫃，排除金融類股
- 最新交易日成交量至少 1,000 張（介面可調整）
- 最新交易日成交量不超過前 20 個交易日平均成交量的設定百分比
- **均線糾結只計算 MA5、MA10、MA20**：三者最大值與最小值之差 ÷ 最新收盤價，不超過設定百分比
- 不要求 MA5 > MA10
- 歷史資料範圍可選 1、2、3 或 6 個月
- MA60 仍顯示於結果表中作為參考，但不納入均線糾結幅度計算

## 更新方式
在 GitHub Repository 中以此版本的 `app.py` 覆蓋舊版，再按 Commit changes。Streamlit Cloud 重新部署後，刷新網站即可。
